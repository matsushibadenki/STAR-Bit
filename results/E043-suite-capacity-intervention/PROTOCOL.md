# E043 preregistration: collision-free delayed admission on frozen suites

Date: 2026-09-29, before E043 outcomes. E042 independently validated an eight-task mixed-difficulty suite with numeric exact 0.500 and routing exact 0.521. E043 freezes that full suite and tests E039's capacity-loss mechanism on new seeds while separating learned Function semantics from inert and same-cost random controls. No task may be removed or reweighted from E043 outcomes.

Use fresh seeds 1590–1595, all eight E042 tasks, beam 128, four rounds, and maximum tree cost 16. Run seven conditions for every seed/task: `no_transfer`; delayed round-two `learned_replace`, `learned_add`, `inert_replace`, `inert_add`, `random_replace`, and `random_add`. `replace` substitutes the last round-one selected entry and keeps realized width 128; `add` appends one entry for round two at realized width 129. Inert conditions insert the frozen learned signature but prohibit every composition involving it. Random conditions use a seed/task-specific expression with the same primitive, routing, and depth cost as the learned Function.

Before any four-round outcome search, compute only the round-one selected beams for all 48 seed/task pairs. Abort if the learned signature collides. Generate all random controls while excluding the union of these round-one signatures, all suite targets, prior targets/inputs, the learned signature, and previously generated random signatures. Thus every delayed insertion is noncolliding by construction. These preflight beams may be used only for collision and width checks, not to choose tasks, conditions, Functions, or seeds.

The primary capacity metric is the per-seed mean over eight tasks and learned/inert/random types of `exact(add)−exact(replace)`. The capacity gate requires mean at least +0.10 and two-sided exact sign-flip p≤0.05. Learned-semantic secondary gates compare `learned_add−inert_add` and `learned_add−random_add`, each averaged over all eight tasks per seed and Holm corrected over the two tests; both means must be positive with Holm p≤0.05, and at least one learned-add exact expression must contain the learned signature. Report bootstrap 95% CI, unbiased variance, and Cohen dz for all paired metrics. Report numeric and routing capacity effects separately, condition/family exact and best error, Function use, generated signatures, elapsed time, and solution primitive/routing/depth.

Run all 336 searches regardless of interim outcomes. Re-evaluate every exact expression over all 64 inputs. Verify 336 unique records, strict JSON, progress equality, source hashes, exact E042 suite membership, 48 identical round-one comparisons per delayed policy, 288 noncolliding injections, replace/add widths 128/129, all 48 random Functions' uniqueness and cost, and no transfer use in baseline/inert conditions. Stop after 336 searches or 15 minutes of summed search time, preserving incomplete state. This experiment measures symbolic search reachability, not physical gate count, inference latency, Router learning, or low-bit model accuracy.
