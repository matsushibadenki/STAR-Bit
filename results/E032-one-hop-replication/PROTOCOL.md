# E032 preregistration: independent one-hop propagation replication

Date: 2026-09-22, before E032 outcomes. E031 was exploratory for `numeric_unsigned_sum_ge6`: the frozen E026 Function solved 0/8, while a one-hop barrier solved 6/8. This task was selected from E031 outcomes, so the following is a conditional independent-seed replication, not a new task-family test. Reuse the frozen E026 Function and unchanged E031 task truth tables. Do not refit the Function, tune task thresholds, or inspect new-seed results before fixing analysis.

Run fresh search seeds 1460–1475 on `numeric_unsigned_sum_ge6` (primary) and `route_dual_mux_xnor` (predefined route-selection comparator). Five conditions per task/seed: `no_transfer`; `admitted` (unrestricted frozen Function); `one_hop_barrier` (Function-containing expressions may generate children in round 1 but cannot serve as parents in rounds 2–6; clean same-signature replacements may compose); `inert_slot` (same frozen Function is in the initial beam but never allowed as a composition parent); and `random_matched` (one deterministic, expression-tree/cost-matched random Function per seed/task, frozen before any E032 search). The inert slot controls initial candidate count/ranking without Function-derived children. The random Function controls structure and cost, not routing; this experiment has no learned Router. All runs use the E026 selector, beam 128, six rounds, tree cost ≤16, one CPU thread. Stop after exactly 160 searches regardless of outcome. Save each row immediately so an interruption is auditable.

Primary metric: paired exact success on numeric `one_hop_barrier - admitted`. Call the E031 signal replicated only if the mean gain is at least +0.25, the two-sided exact sign-flip p is at most .05, and the 20,000-resample paired bootstrap 95% interval excludes zero. The mechanism-specific gate requires, additionally, `one_hop_barrier - inert_slot` mean at least +0.125 with exact sign-flip p at most .05. This gate tests whether one permitted generation round helps beyond candidate-count/ranking effects. Do not interpret a replication without the second gate as proof of beneficial one-hop composition.

Secondary numeric contrasts: barrier versus no transfer and random; admitted versus inert and random; inert versus no transfer. Report paired means, unbiased variances, Cohen dz, bootstrap intervals and exact sign-flip p. Apply Holm correction across these six secondary contrasts. Report per-condition exact success, best error, solution tree cost, Function use, and elapsed time. The route task is descriptive: compare the same conditions and report route/numeric interaction on barrier-minus-admitted, without selecting another task or seed based on outcome.

Re-evaluate all exact expressions over all 64 inputs, verify random Library cost, task signatures, unique random signatures, source hashes, row count, and strict JSON. This is a Boolean search-dynamics experiment. It cannot establish learned routing, abstract concepts, description compression, gate count reduction, or hardware speed.
