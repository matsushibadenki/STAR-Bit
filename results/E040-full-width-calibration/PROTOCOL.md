# E040 preregistration: full-width baseline difficulty calibration

Date: 2026-09-26, before E040 search outcomes. E039 could not test its exact endpoint because its new numeric task was at floor and its routing task near ceiling; its configured numeric beam cap 192 also realized only 164 entries. E040 is an exploration-only baseline calibration. It does not test Function transfer. It freezes three new exact-numeric and three new routing truth tables before search, then finds whether either family contains a middle-difficulty, fully populated beam setting for an independent E041 capacity confirmation.

Use fresh seeds 1550–1555, no Library, maximum tree cost 16, beam 128, and one deterministic five-round search per seed/task. Derive the prefix-equivalent outcomes at round budgets 3, 4, and 5 from each run's solution round and best-error history; do not rerun or add seeds after seeing outcomes. Numeric tasks use two exact 2-bit integers `x=b0+2*b1`, `y=b2+2*b3`: `sum_ge3`, `absdiff_ge2`, and `product_ge3`. Routing tasks are fixed rotated cross-mux XOR, its XNOR complement, and a nested mux (`u=mux(b0,b2,b4)`, `v=mux(b3,b5,b1)`, `out=mux(b2,u,u xor v)`). Assert that all six signatures are unique and absent from prior target sets before searching.

A task/budget is eligible only when baseline exact is 2–4 of 6 seeds and every unsolved run has an actual round-two input width of exactly 128. Within each family select the eligible setting with the fewest rounds, breaking ties by the task order above. The feasibility gate is one frozen eligible setting in both families. This gate is only permission to run independent E041 seeds, not evidence that routing or structural freedom helps.

Report exact and best-error mean/unbiased variance for every task/budget, maximum-run elapsed time and generated signatures, actual round-two width, solution primitive/routing/depth costs, and all selected settings. As descriptive sensitivity analysis, compare round 5 minus round 3 exact for each task using paired differences, 20,000-resample bootstrap 95% CI, Cohen dz, exact sign-flip p, and Holm correction over six comparisons. Re-evaluate every exact expression over all 64 inputs. Verify 36 unique maximum runs, 108 derived task/budget rows, prefix consistency, strict JSON, progress equality, source hashes, target uniqueness, no Library signatures, and beam width. Stop after 36 searches or 15 minutes of summed search time, preserving incomplete state. Do not use any Function-condition result for task selection.
