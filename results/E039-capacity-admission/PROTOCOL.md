# E039 preregistration: delayed admission capacity versus replacement

Date: 2026-09-25, before E039 outcomes. E038 found that delayed learned, inert, and same-cost random insertion had identical success counts on two previously inspected tasks. E039 tests whether the remaining effect comes from replacing one selected beam entry rather than adding semantic structure. This is a prospective-task mechanism pilot: freeze two new noncolliding truth tables before search, `numeric_rotated_weight_ge6` with weights `(3,1,2,1,3,2)` and threshold 6, and `route_cross_implies` using the same cross-mux pair as E033 followed by implication. The targets were checked only for signature uniqueness/noncollision, not search outcomes.

Use fresh seeds 1540–1545. Numeric uses beam 192, six rounds; route uses beam 128, four rounds; tree cost ≤16. Freeze E026's learned Function. For every seed/task run seven conditions: `no_transfer`; delayed round-two `learned_replace`, `learned_add`, `inert_replace`, `inert_add`, `random_replace`, `random_add`. Replacement substitutes the last round-one selected entry and retains the configured width. Addition appends the Module for round two, temporarily making width+1, then selection returns to the configured width. Inert blocks every composition involving its signature. Random controls use a frozen seed/task-specific same-cost Function. All delayed conditions must have identical round-one selected beams and best error to no-transfer. Run all 84 searches regardless of interim outcomes and persist every row.

Primary metric is the seed-level mean across both tasks and all learned/inert/random Module types of exact(add)−exact(replace). The capacity-preservation pilot gate is mean ≥+0.20 and two-sided exact sign-flip p≤0.05, with unbiased variance, Cohen dz, and 20,000-resample bootstrap 95% CI. Secondary comparisons, Holm corrected over four tests, are task-specific pooled add−replace, learned add−inert add pooled across tasks, and learned add−random add pooled across tasks. A learned-semantic claim requires both learned-add contrasts positive with Holm p≤0.05 and at least one successful expression using the learned signature. Otherwise, an add advantage is capacity/beam evidence.

Report exact and best-error mean/unbiased variance, generated signatures, elapsed time, Function use, and exact-solution primitive/routing/depth costs by task/condition. Re-evaluate all exact expressions over 64 inputs. Verify 84 unique records, strict JSON, progress equality, source hashes, new target signatures, all 12 random controls' cost/uniqueness, round-one equality, configured post-injection widths, and an unrelated smoke comparison against E038 replacement behavior. Stop after 84 searches or 15 minutes of summed local CPU search time, preserving incomplete state; do not add seeds or conditions from outcomes. This experiment does not measure physical gate reduction, inference latency, or Router learning.
