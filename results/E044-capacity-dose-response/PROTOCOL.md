# E044 preregistration: frozen-suite capacity dose–response

Date: 2026-09-30, before E044 outcomes. E043 showed that a one-entry delayed replacement/addition left every frozen-suite exact rate unchanged. The new hypothesis is that this null result reflects an intervention below the search system's response scale. E044 measures a semantic-free capacity dose–response without selecting new tasks or using any learned Function.

Freeze all eight E042 tasks, fresh seeds 1600–1605, four rounds, maximum tree cost 16, and beam widths 64, 96, 128, 160, and 192. Width 128 is the reference control; 64/96 are capacity reductions and 160/192 are expansions. Every seed/task/width is run once, for 240 searches. No task, seed, or width may be removed or reweighted from outcomes, and no Function result is consulted.

The preregistered primary metric is the per-seed mean over all eight tasks of `exact(width192)−exact(width64)`. Capacity sensitivity requires mean at least +0.10 and a two-sided exact sign-flip p≤0.05. Secondary family contrasts use the same endpoint separately for numeric and routing, Holm corrected across two families. Best-error reductions `error64−error192` are reported as sensitivity diagnostics, with Holm correction across families, but cannot replace a failed primary exact gate. The local contrast `width160−width96`, all five width means, per-task endpoints, unbiased variance, paired bootstrap 95% CI, Cohen dz, generated signatures, elapsed time, and solution primitive/routing/depth are also reported. A future semantic experiment may change intervention scale only from the frozen width response, never from learned-Function outcomes.

Run all 240 searches regardless of interim outcomes. Re-evaluate every exact expression on all 64 inputs. Verify unique records, strict JSON, progress equality, source hashes, exact E042 suite membership, no Library use, requested/realized round-one and round-two widths, and deterministic prefix nesting of first-round beams across widths for each seed/task. Stop after 240 searches or 15 minutes of summed search time, preserving incomplete state. This is calibration of symbolic search sensitivity, not evidence for learned abstraction, physical gate reduction, inference speed, Router learning, or low-bit accuracy.
