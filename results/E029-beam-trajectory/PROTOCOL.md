# E029 preregistration: Library-induced beam trajectory

Date: 2026-09-18, before E029 outcomes.

E028 found that an input-rotated two-gate Function reached 4/16 dual-mux XOR targets while appearing in none of those final circuits. Test the proposed indirect beam-trajectory mechanism on new seeds, without changing the Function or choosing seeds after inspection. This is a mechanistic trace experiment, not an independent statistical confirmation of E027 transfer.

Freeze E026's admitted Function and the +1 cyclic input-index rotation defined in E028. Run seeds 1410–1425 on E024's held-out `eval_dual_mux_xor` and numeric-control `eval_threshold2`. For each paired seed and task compare `no_transfer`, `admitted`, and `rotate1`: 96 searches total, E026's signature-stable deterministic algorithm, beam 128, six rounds, tree cost at most 16, no protected slots. Run CPU with one thread. Do not reselect Functions or tune the budget.

Instrument E026's beam-selection call without changing its return value. At each round save selected beam signatures, the injected Function's parent credit and partner count, whether it survives selection, and selected signatures generated by a direct pair with that Function. Save exact final expression and all ordinary search metrics. Verify the wrapper returns exactly the original selected beam on a pre-run smoke comparison.

Primary mechanism indicator for `rotate1` on dual-mux XOR: among exact solutions present only with `rotate1` relative to no transfer, count cases where the final expression omits the rotated Function but includes a signature from the round-1 rotated beam that was absent from the round-1 no-transfer beam. Distinguish whether that ancestor signature was directly generated by a pair with the injected Function. Report the count with denominator and do not call it causal proof; multiple generation paths can share a signature. A preliminary trajectory witness requires at least three such cases. Also report paired exact differences per seed, mean/unbiased variance, 20,000-resample bootstrap CI, Cohen dz, exact sign-flip p, three-condition exact McNemar comparisons with Holm correction, task-specific best-error and runtime, and beam Jaccard overlap by round. The numeric task is descriptive; do not claim an interaction without testing it.

Stop after all fixed 96 searches regardless of outcome. Save raw records, source hashes, protocol, frozen Function manifest, audit and report under E029; re-evaluate every exact expression on all 64 inputs. A positive trajectory witness supports a search-path mechanism only, not learned abstract knowledge, gate-count compression, hardware speed, or Router learning.
