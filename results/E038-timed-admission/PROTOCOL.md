# E038 preregistration: timed Function admission mechanism pilot

Date: 2026-09-22, before E038 outcomes. E037's independent seeds showed no successful expression using the learned Function and the numeric target's one-hop barrier matched inert/no-transfer on all six seeds. E038 is an **exploratory mechanism pilot on previously inspected tasks**, not a fresh task-family confirmation. Freeze the same two targets and within-task budgets: `numeric_symmetric_ge5` at beam 256 / six rounds, and `route_cross_and` at beam 128 / four rounds; tree cost ≤16. Freeze E026's admitted Function. Use only new seeds **1530–1535**; do not revise seeds or thresholds after seeing results.

For each seed/task run five conditions, 60 searches total: `no_transfer`; `early_learned` (the Function is in the initial beam); `late_learned` (insert after round-one beam selection, immediately before round two); `late_inert` (same insertion and cost, but forbid every pairwise composition involving its signature); `late_random` (same-cost random Function inserted on the same schedule). If round one already solves the target, return without an insertion. For late conditions, replace the last selected beam entry with the Module, preserving the configured beam width. The first round must have identical search history and selected beam for all no-transfer/late conditions. A late Module with an already selected signature replaces its representative; record whether this occurs. Generate and freeze all 12 random controls before searching, excluding input, old/current target, probe/evaluation, admitted, and other random signatures.

Implementation check before evaluation: on an unrelated prior target with a distinct smoke seed, verify this search implementation agrees with E026's original no-transfer and early-Function search on exact, round, best-error history, generated-signature count, solution expression, and transfer usage for two rounds. Do not choose any settings based on this smoke outcome.

Primary metric is the paired seed-level mean over the two frozen tasks of exact(`late_learned`) minus exact(`early_learned`). A directional pilot signal requires mean ≥+0.25 and two-sided exact sign-flip p≤0.05, reported with mean, unbiased variance, Cohen dz, and 20,000-resample bootstrap 95% CI. This threshold can establish only a timing effect for the frozen tasks; it cannot establish Function semantics or task-family generality. Secondary paired exact contrasts, Holm corrected over four comparisons, are numeric and route `late_learned−early_learned`, pooled `late_learned−late_inert`, and pooled `late_learned−late_random`. Report each condition/task's exact and best-error means/unbiased variances, generated signatures, elapsed time, successful-expression Function use and primitive/routing/depth cost. A learned-Function-specific claim needs `late_learned−late_inert` positive with Holm p≤0.05 **and** at least one successful final expression containing the learned signature; otherwise any benefit may be a beam perturbation.

Verify every exact expression on all 64 inputs, 60 unique records, progress equality, strict JSON, all source hashes, frozen random Function cost/uniqueness, early/no-transfer smoke equivalence, and first-round history/beam equality among no-transfer/late variants. Stop after all 60 searches or at 15 minutes of CPU work with incomplete progress saved. No external compute, publication, or third-party messages. Keep negative outcomes and separate this exploratory phase from any later prospective task confirmation.
